# Changelog

## 1.0.0 — first public release
- First public version, tested with the published packages (r2modman layout).

## 0.3.0
- One folder per language (`FR`, `DE`…), chosen from the game's language (setting `General.Language`).
- English file names accepted (`names.json`, `texts.json`); reports `detected-cards.txt` and `detected-texts.txt` in the language folder.
- Settings and messages in English or French.

## 0.2.0
- Disk cache of prepared images; edition, product, decoration and shop names (`texts.json`).

## 0.1.0
- Translated card images and names for Enhanced Prefab Loader packs.
