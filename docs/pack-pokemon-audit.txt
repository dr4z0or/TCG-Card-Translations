FURNITURE OVERHAUL  v1.6.1
==========================

The furniture shop on the phone, redesigned, and the Diamond Collection: 44 pieces of shop furniture
in walnut, black metal and brass, built for a card shop. Singles walls and towers, retail
shelves, a checkout desk, a cart you push, a claw machine, a vending machine that stands
outside, a comic tower, turning spinners and more. With CardGrade Overhaul
installed, three grading pieces join them: a card scanner, a loupe table and a cracking bench.
Everything is bought in the shop, placed, moved and boxed like the game's own furniture, and
saves with the game.

Requires BepInEx 5.4.x (x64) only. No other mod is needed. The three grading pieces need
CardGrade Overhaul; without it they are not sold.


THE FURNITURE SHOP
------------------
  The game's own furniture shop gets a full page instead of the small list:

  ALL              everything you can buy, in level order
  VANILLA ITEMS    the game's own furniture
  DIAMOND COL.     the Diamond Collection
  GRADING          the card scanner, loupe table and cracking bench (only with CardGrade Overhaul)
  OTHER           furniture from other mods, grouped by mod (Enhanced Prefab Loader packs)

  A KIND filter narrows the list (card displays, retail shelves, checkout, storage, tables,
  machines, decor). Click a card to see the piece in live 3D (drag to turn it), the
  description, the level it needs and the price; set a quantity and BUY. Bought furniture
  arrives in boxes as usual.

  FINISHES: every Diamond piece can be bought in your own colours. Pick the body, the wood,
  the metal trim and the card holders (rugs: style, colour and border) from the swatches
  above Quantity; the 3D view shows the result before you buy, and the finish saves with the
  game.

  CONTROLLER: the whole page works with a gamepad. D-pad or left stick moves, A selects and
  buys, B goes back, LB / RB switch tabs, the triggers or the right stick scroll. With an item
  selected, X (Xbox) or Square (PlayStation) jumps straight to the Buy button.

  Furniture from other mods that plug into this shop gets its own tab while that mod is
  installed. With many tabs the tab column scrolls. The page can be switched off in the settings file (see SETTINGS); the phone
  then opens the game's own furniture list.

HOW THINGS WORK
---------------
  * Refinish: aim at a placed Diamond piece and press P to paint it in new colours. It costs a
    little, like buying the finish.
  * Buying, placing, moving, boxing and saving use the game's own systems. Every piece has
    its own stable object type, so a save with Diamond furniture in it loads again exactly.
  * Product icons are rendered from the real models the first time the shop opens and cached
    in BepInEx\cache\FurnitureOverhaul. The first opening takes a moment.
  * The claw machine and the checkout keep a small companion file next to the game saves
    (FurnitureOverhaulClaw, FurnitureOverhaulCheckout in the game's save folder). Losing it
    never loses stock; it only holds poses, fees and statistics.
  * Optional: with Pallet Delivery installed the cart can load from staged delivery cargo.
    With Enhanced Prefab Loader packs installed their furniture appears under OTHER.


SETTINGS
--------
  BepInEx\config\com.qolmods.furnitureoverhaul.cfg (or Configuration Manager, F1):

  [Shop] NewFurnitureShop     true = the new furniture page, false = the game's own list.
  [CardScanner]               seconds per card, tray and output box sizes, auto start, auto
                              add to the album, sounds and volume of the Diamond Card Scanner.
  [Debug] VerboseLogging     false = only one line in the log at start (warnings and errors
                              are always written); true = the full details, for bug reports.


INSTALLATION
------------
  1. Install BepInEx 5.4.x (x64) and start the game once so BepInEx creates its folders.
     Close the game before installing or updating the mod.
  2. Extract the archive into the game folder (the folder that contains BepInEx).
  3. The DLL must sit at  BepInEx\plugins\FurnitureOverhaul\FurnitureOverhaul.dll
  4. Start the game. The settings file is created on first start.

  Vortex: install the archive as usual, its folders mirror the game folder.

  Never keep two copies of the DLL (for example one in BepInEx\plugins and one in
  BepInEx\scripts). Remove older copies first.


UNINSTALLING
------------
  Box up every Diamond piece and sell or store the boxes BEFORE removing the mod. A save
  that still contains Diamond furniture cannot be loaded by the game without the mod: the
  game does not know the object types. Keep a backup of your saves before removing it.


KNOWN LIMITATIONS

PURCHASE OVERHAUL  v1.3.0
Formerly One Purchase.

One phone app for every shop order. Browse vanilla stock, board games and every expansion shop
in one grid, search across all of them, fill one cart and place one order with one delivery fee.


INSTALL
-------
  1. BepInEx 5.4.x (x64) must be installed. Start the game once so BepInEx creates its folders.
  2. Drop the BepInEx folder from this zip into your game folder, so the file ends up at
     ...\TCG Card Shop Simulator\BepInEx\plugins\PurchaseOverhaul\PurchaseOverhaul.dll
  3. Start the game. The Purchase Overhaul app is on the phone.

  Vortex: install the zip as a normal mod.

  Coming from One Purchase: your settings carry over by themselves. If the old
  BepInEx\plugins\OnePurchase folder is still there, Purchase Overhaul switches it off and
  renames the old file so it no longer loads. You can delete that folder.


REQUIRES
--------
  BepInEx 5.4.x (x64)

  Recommended, not required:
    Phone Overhaul       the app gets its own tile on the phone home screen. Without it, the
                         vanilla Order Stock tile opens Purchase Overhaul instead.
    Enhanced Prefab Loader   its shops show up in the app on their own, with their own tile.


HOW TO USE
----------
  * Open the app from the phone.
  * The left rail lists every shop that has products, plus All shops at the top.
  * The category chips filter the grid, the search field searches every shop at once.
  * Click a product to open it, set the number of boxes and add it to the cart.
  * The cart button at the top right opens the cart. Lines are grouped per shop.
  * Place the order once. Every box arrives at the delivery spot as usual, one delivery fee
    for the whole order.
  * A product you have not unlocked says so, and the licence can be bought from the same page.
    Products you own the licence for are listed first.
  * Drag a shop in the left rail to change the order of the shops.
  * Each product shows how many boxes you have in the warehouse and on your shelves.
  * Restock warehouse in the cart fills the cart with what your labelled warehouse shelves
    are missing, minus boxes already on the way.
  * Auto restock under it places that order by itself once a day at the time you pick.


CONTROLLER
----------
  D-pad / left stick   move between the shops, the filters, the products, the product panel
                       and the cart
  A / Cross            press the button in focus. Press it again on the chosen product to jump
                       to Add to cart, hold it on - and + to count fast
  B / Circle           close the cart, or leave the app
  X / Square           open or close the cart
  LB / RB              previous or next shop
  LT / RT              page through the products, the shops or the cart
  Right stick          scroll


SETTINGS
--------
  BepInEx\config\com.qolmods.purchaseoverhaul.cfg (or Configuration Manager, F1):
    Phone     ReplaceStockOrderTile
    Catalogue ShowLockedItems, ShopOrder
    Cart      MaxBoxesPerLine
    Restock   AutoRestock, AutoRestockTime


UNINSTALL
---------
  Delete BepInEx\plugins\PurchaseOverhaul. Nothing is written to your save.
